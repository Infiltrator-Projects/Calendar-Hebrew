# Hebrew Calendar — architecture

The Hebrew chronology, formatter and provider-specific ICU adapter belong to this repository. Common 1.19.80 (dc4aac326964ca4400b6e21851d16eea674040c8) owns public ABI, generic arithmetic and civil/date coordinate calculations. Builds compile and link the Common static archive from the exact git submodule; no Common source/header snapshots are compiled locally. The release's native .run and source ZIP include the reviewed Common tree for offline rebuilds. Historical copy provenance stays in SOURCE-MANIFEST.json, and provider/accuracy fixture tests remain mandatory.
